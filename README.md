# 无线麦Mod（Win 版）

把谷歌 Chromecast 蓝牙语音遥控器的按键和麦克风变成 Windows 快捷操作与语音输入工具。可远距离控制应用、输入文字、触发 Quicker 动作。

> ⚠️ **本仓库是修改版（Mod）**：基于 [ZSTDJan/windows-remote-mic-app](https://github.com/ZSTDJan/windows-remote-mic-app) 修改，已**移除小米 RC003 遥控器**的全部支持，仅保留谷歌 Chromecast 遥控器链路；产品名改为「无线麦Mod」。
> 本修改版按上游同样的 **GPL-3.0-only** 许可证发布。完整许可证见 [LICENSE.md](LICENSE.md)，修改声明见 [NOTICE.md](NOTICE.md)。本 Mod 与上游作者无隶属关系，按“原样”提供，无任何担保。

## 与原版的区别

- **仅支持谷歌 Chromecast 遥控器**：不再包含小米遥控器 2 Pro 的代码、配置与界面。
- 设备档案固定为 `config/chromecast-remote.json`，Python 包名改为 `ovb`，产品显示名「无线麦Mod」。
- 新增“应用日志”开关：关闭后运行时停止生成 `app.log`，无需重启。
- 默认窗口尺寸从 560 调整为 600（避免设备页内容溢出）。
- 修复遥控器**音量 / 静音键**在“物理键防护”下被误杀、导致按键永久失效的问题（仅对音量 / 静音三键放行瞬间点按，其余键防护不变）。

## 能做什么

- 给遥控器按键设置方向、确认、音量、快捷键、鼠标操作或 Quicker 动作；同一按键可分别设置单击、双击和长按。
- 用遥控器话筒键说话，在文字输入框中使用搜狗、微信、豆包或 Chatterfly 输入文字。
- 在通知区域保持运行；关闭设置窗口通常会隐藏，结束程序请从通知区域选择“完全退出”。

## 第一次使用

- **系统兼容性**：开发环境为 Windows 11 23H2。较早 Windows 版本的兼容性尚未全面验证。
- **首次配置前，请先暂时退出 360 等杀毒软件；配置和测试完成后及时恢复防护。**
- **首次使用语音前，必须先安装虚拟音频组件 VB-CABLE，并重启电脑；重启后再配置语音。**

### 先让遥控器按键可用

1. 在 Windows 蓝牙设置中配对 Chromecast 遥控器。
2. 打开无线麦Mod，进入“设备”页。
3. 点“选择设备”，选中刚配对的遥控器并点“使用此设备”。
4. 点“启动服务”，查看连接状态；如有未就绪提示，按页面说明处理。
5. 连接后按一次方向键，确认能控制电脑。

### 再设置语音输入

**语音需要在无线麦Mod 和对应输入法两边分别配置，只设置一边还不够。**

1. 在“语音”页点击“安装音频”，安装虚拟音频组件 VB-CABLE，**安装完成后先重启电脑**。
2. 重启后，在无线麦Mod“语音”页选择搜狗、微信、豆包或 Chatterfly。
3. 在无线麦Mod 中，把“输出端点”设为 `CABLE Input`。
4. 打开对应输入法或 Chatterfly 的设置，把麦克风设为 `CABLE Output`。
5. 在无线麦Mod 中确认“按键模式”：谷歌遥控器支持按住型和开关型。

**搜狗、微信和豆包还需要配置语音快捷键：** 在输入法设置中为所选语音模式设置快捷键，并让无线麦Mod 的“语音按键”与之保持一致（自动读取失败可手动录入）。

最后，把光标放在文字框里，用遥控器话筒键测试：

- 按住型：按住说话，松开结束。
- 开关型：按一次开始，再按一次结束。

## 从源码运行

- 环境：Windows 10/11，Python 3.13 或 3.14，PySide6，Frida。
- 以提权（管理员）运行仓库根目录的 `启动无线麦源码版-提权.bat`，或以普通权限运行 `启动无线麦源码版.bat`；两者本质都是 `pyw.exe -m ovb ...` 启动源码。
  （`src/launcher.py` 仅供打包形态使用，源码运行直接走 `-m ovb`，请勿删除。）
- 便携模式（配置与日志落在仓库内 `config/`、`log/`）：启动时带 `--remote-mic-dev-session`。

### 运行测试

